# Third-party software

H TRANS bundles the official Windows release of **scrcpy 4.1** by Genymobile for Android screen mirroring.

- Project: https://github.com/Genymobile/scrcpy
- License: Apache License 2.0
- H TRANS uses the unmodified official Windows x64 release archive at build time.

H TRANS also bundles Google's official Android SDK Platform-Tools for ADB connectivity.
